# Web Security Learning Roadmap

## Phase 0: Linux and networking

Learn:

- files and directories,
- permissions,
- processes,
- ports,
- IP addresses,
- DNS,
- HTTP basics.

## Phase 1: Docker

Learn:

```text
Image
  ->
Container
  ->
Network
  ->
Volume
  ->
Compose
```

## Phase 2: Web fundamentals

```text
Browser
  ->
HTTP request
  ->
Web server
  ->
Application
  ->
Database
  ->
HTTP response
  ->
Browser rendering
```

Learn:

- GET and POST,
- headers,
- cookies,
- sessions,
- forms,
- JavaScript,
- same-origin concepts.

## Phase 3: SQL Injection

Focus:

- untrusted input,
- query construction,
- parameterized queries,
- server-side validation,
- database least privilege.

## Phase 4: XSS

Focus:

- untrusted data,
- HTML contexts,
- browser interpretation,
- output encoding,
- sanitization,
- content security concepts.

## Phase 5: CSRF

Focus:

- authenticated browser sessions,
- automatic credentials,
- request origin,
- CSRF tokens,
- SameSite cookies,
- sensitive state changes.

## Phase 6: Clickjacking

Focus:

- frames,
- UI deception,
- browser frame protections,
- click target control.

## Phase 7: Shellshock

Focus:

- vulnerable software,
- server-to-process interaction,
- patching,
- exposure management,
- containment.
